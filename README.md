**Готовые системные инструкции (текстовые экшены) для ChatGPT, Claude, Gemini и DeepSeek на базе Смыслового ролевого метода / Метода датированной записи.**

Превращают любую языковую модель в строгий структурный аудитор: вскрывают скрытый пассивный залог («Пустое кресло»), «резиновые» сроки, цифры без базы, обещания без действий и галлюцинации самой нейросети.

## 1. КАРТА ФАЙЛОВ В ЭТОМ РЕПОЗИТОРИИ

### Фундаментальное ядро метода (базис)
1. **[`padezhny-filtr-v1.3.md`](./padezhny-filtr-v1.3.md)** ([`English`](./case-filter-v1.3-en.md)) — **«Падежный фильтр» v1.3**: компактная спецификация Смыслового ролевого метода / Метода датированной записи (формула акта `E = Ω(T) ⟿ σ(O)`, законы кресла и реестр сбоев).

### Готовые сборки «МАКРОС-ОС» (3 лучшие версии без повторов)
2. **[`macro-os-v9.5-complete.md`](./macro-os-v9.5-complete.md)** ([`English`](./macro-os-v9.5-complete-en.md)) — **«Полный пульт четырёх направлений» (автономный, 1 файл)**:
   * Ядро уже вшито внутрь. Лёгкая рабочая станция со «спящими режимами» (экономит токены в чате): включает контуры для очистки длинных статей (`ЛУКОВИЦА:`), сборки и защиты договоров (`КОНСТРУКТОР:`, `СВЕРКА-ПАРА:`, `АДВОКАТ ДЬЯВОЛА:`), контроля ИИ и сквозных проектов (`ЗЕРКАЛО:`, `ЦЕПОЧКА:`, `РЕСУРС:`, `СБОРКА-ДО:`) и проверки сложных задач (`НАВИГАТОР:`, `ВЫРОЖДЕНИЕ:`).
3. **[`macro-os-v8.0-autopilot.md`](./macro-os-v8.0-autopilot.md)** ([`English`](./macro-os-v8.0-autopilot-en.md)) — **«Автопилот» (работает в паре с ядром `v1.3`)**:
   * Надстройка для работы без команд: сама определяет тип текста (договор, новость, отписка или ответ ИИ), проверяет по 5 ролям и пишет правку «КАК НАДО».
4. **[`macro-os-v7.0-tribunal.md`](./macro-os-v7.0-tribunal.md)** ([`English`](./macro-os-v7.0-tribunal-en.md)) — **«Трибунал и Арбитраж» (работает в паре с ядром `v1.3`)**:
   * Надстройка для состязательного разбора спорных записей тремя изолированными ролями (**Прокурор / Защитник / Судья**) с расчётом Индекса расхождения и кросс-модельный `АРБИТРАЖ` для проверки вердиктов других нейросетей.

## 2. КАК ЗАПУСТИТЬ В ОБЫЧНОМ ЧАТЕ (2 ВАРИАНТА)

Откройте новый диалог в **ChatGPT, Claude, Gemini или DeepSeek** и выберите удобный способ:

* **Вариант А — В 1 шаг (автономный «Полный пульт v9.5»):**
  1. Откройте [`macro-os-v9.5-complete.md`](./macro-os-v9.5-complete.md), скопируйте весь текст и отправьте первым сообщением.
  2. Сразу присылайте любой текст для проверки (включится **Автопилот**) или вызывайте нужный режим командой (`ЛУКОВИЦА:`, `СВЕРКА-ПАРА:`, `КОНСТРУКТОР:`, `АДВОКАТ ДЬЯВОЛА:`, `ЗЕРКАЛО:`).

* **Вариант Б — В 2 шага (базовое ядро `v1.3` + надстройка `v8.0` или `v7.0`):**
  1. Первым сообщением отправьте в чат базовое ядро **[`padezhny-filtr-v1.3.md`](./padezhny-filtr-v1.3.md)**.
  2. Вторым сообщением отправьте выбранную надстройку: **[`macro-os-v8.0-autopilot.md`](./macro-os-v8.0-autopilot.md)** (для автоматического разбора без команд) или **[`macro-os-v7.0-tribunal.md`](./macro-os-v7.0-tribunal.md)** (для режима Трибунала и Арбитража).

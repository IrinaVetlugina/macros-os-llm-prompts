**Полный набор готовых системных инструкций (текстовых экшенов) и базовое ядро «Падежного фильтра» v1.3 для ChatGPT, Claude, Gemini и DeepSeek.**

Превращают любую языковую модель в строгий структурный аудитор: вскрывают скрытый пассивный залог («Пустое кресло»), «резиновые» сроки, цифры без базы, обещания без действий и галлюцинации самой нейросети.

---

### Попробовать без регистрации и установки (прямо в браузере)

## 1. КАРТА ФАЙЛОВ В ЭТОМ РЕПОЗИТОРИИ

### Фундаментальное ядро метода (базис)
1. **[`padezhny-filtr-v1.3.md`](./padezhny-filtr-v1.3.md)** ([`English`](./case-filter-v1.3-en.md)) — **«Падежный фильтр» v1.3**: компактная спецификация Смыслового ролевого метода / Метода датированной записи (формула акта `E = Ω(T) ⟿ σ(O)`, законы кресла и реестр сбоев).

### Готовые сборки «МАКРОС-ОС» (3 лучшие версии без повторов)
2. **[`macro-os-v8.0-autopilot.md`](./macro-os-v8.0-autopilot.md)** ([`English`](./macro-os-v8.0-autopilot-en.md)) — **«Автопилот» (старт в 1 шаг без команд)**:
   * Идеально для быстрого знакомства. Просто вставьте файл в начало диалога и присылайте любой текст (договор, новость, отписку или ответ ИИ) без специальных команд — система сама определит тип текста, разберёт по 5 ролям и напишет правку «КАК НАДО».
3. **[`macro-os-v9.5-complete.md`](./macro-os-v9.5-complete.md)** ([`English`](./macro-os-v9.5-complete-en.md)) — **«Полный пульт четырёх направлений»**:
   * Основная лёгкая рабочая станция со «спящими режимами» (экономит токены в чате). Включает контуры для очистки длинных статей (`ЛУКОВИЦА:`), сборки и защиты договоров (`КОНСТРУКТОР:`, `СВЕРКА-ПАРА:`, `АДВОКАТ ДЬЯВОЛА:`), контроля ИИ и сквозных проектов (`ЗЕРКАЛО:`, `ЦЕПОЧКА:`, `РЕСУРС:`, `СБОРКА-ДО:`) и проверки сложных задач (`НАВИГАТОР:`, `ВЫРОЖДЕНИЕ:`).
4. **[`macro-os-v7.0-tribunal.md`](./macro-os-v7.0-tribunal.md)** ([`English`](./macro-os-v7.0-tribunal-en.md)) — **«Трибунал и Арбитраж»**:
   * Состязательный разбор спорных записей тремя изолированными ролями (**Прокурор / Защитник / Судья**) с расчётом Индекса расхождения и кросс-модельный `АРБИТРАЖ` для проверки вердиктов других нейросетей.

## 2. КАК ЗАПУСТИТЬ ЗА 30 СЕКУНД

1. Откройте новый чат в **ChatGPT, Claude, Gemini или DeepSeek**.
2. Откройте нужный файл выше (новичкам рекомендуем [`macro-os-v8.0-autopilot.md`](./macro-os-v8.0-autopilot.md)), скопируйте его содержимое целиком и отправьте первым сообщением.
3. Далее просто присылайте тексты для проверки или используйте команды выбранного пульта (`ЛУКОВИЦА:`, `СВЕРКА-ПАРА:`, `КОНСТРУКТОР:`, `АДВОКАТ ДЬЯВОЛА:`, `ТРИБУНАЛ:`, `ЗЕРКАЛО`).

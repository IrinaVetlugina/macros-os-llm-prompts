## 1. КАРТА ФАЙЛОВ РЕПОЗИТОРИЯ

### Автономные браузерные студии (HTML / GitHub Pages)
1. **`macros_os_studio.html`** / **`macros_os_studio_en.html`** — единый браузерный комбайн «Всё в одном» (Автопилот, Договоры, Новости/Отписки, Зеркало ИИ + шаблон правки «КАК НАДО»).
2. **`observer_trainer_ru.html`** / **`observer_trainer_en.html`** — интерактивный Пульт Наблюдателя для освоения 18 структурных ловушек.

### Текстовые экшены для любых нейросетей (папка `macros-os-versions/`)
3. **[`macros-os-versions/macro-os-v8.0-autopilot.md`](./macros-os-versions/macro-os-v8.0-autopilot.md)** — **«Автопилот» (старт в 1 шаг без команд)**: сам определяет тип текста, проверяет по 5 ролям и выдаёт правку «КАК НАДО».
4. **[`macros-os-versions/macro-os-v9.5-complete.md`](./macros-os-versions/macro-os-v9.5-complete.md)** — **«Полный пульт четырёх направлений»**: лёгкая рабочая станция со «спящими режимами» для новостей (`ЛУКОВИЦА`), договоров (`КОНСТРУКТОР`, `СВЕРКА-ПАРА`, `АДВОКАТ ДЬЯВОЛА`), контроля ИИ (`ЗЕРКАЛО`, `ЦЕПОЧКА`, `РЕСУРС`) и разбора сложных задач (`НАВИГАТОР`, `ВЫРОЖДЕНИЕ`).
5. **[`macros-os-versions/macro-os-v7.0-tribunal.md`](./macros-os-versions/macro-os-v7.0-tribunal.md)** — **«Трибунал и Арбитраж»**: состязательный разбор спорных записей тремя контурами (Прокурор / Защитник / Судья) и перекрёстная проверка вердиктов других нейросетей (`АРБИТРАЖ`).
6. **`padezhny-filtr-v1.3.md`** / **`case-filter-v1.3-en.md`** — сверхлёгкое фундаментальное ядро метода (русская и английская спецификации).

### Инфраструктура и код (Python / MCP)
7. **`case_filter_mcp_server.py`** — **MCP-сервер (Model Context Protocol)** для Claude Desktop, Cursor, Windsurf и корпоративных ИИ-агентов. Блокирует отправку писем и согласование договоров с пассивом, цифрами без базы и резиновыми сроками (время отклика `< 0.5 мс`, без внешних зависимостей).
8. **`case_compiler.py`** — автономный Python-компилятор для проверки текстов и файлов без обращения к LLM.

## 2. БЫСТРЫЙ СТАРТ В ОБЫЧНОМ ЧАТЕ (БЕЗ ПРОГРАММИРОВАНИЯ)

1. Откройте новый диалог в ChatGPT, Claude, Gemini или DeepSeek.
2. Скопируйте содержимое выбранного файла из папки **`macros-os-versions/`** (новичкам лучше начать с **`macro-os-v8.0-autopilot.md`**, для полной функциональности выберите **`macro-os-v9.5-complete.md`**) и отправьте первым сообщением.
3. В **«Автопилоте v8.0»** просто присылайте любой текст без команд — система разберёт его сама.
4. В **«Полном пульте v9.5»** доступны точечные команды:
   * `ЛУКОВИЦА: [текст]` — очистка длинной статьи или отчёта до сухого ядра фактов.
   * `КОНСТРУКТОР: [задача]` / `АДВОКАТ ДЬЯВОЛА: [договор]` — сборка и защита пунктов договора.
   * `СВЕРКА-ПАРА: [Текст А] /// [Текст Б]` — сравнение обещаний в рекламе с текстом договора.
   * `ЦЕПОЧКА:` / `РЕСУРС:` — склейка документов по датам и проверка бюджета под задачу.
   * `ЗЕРКАЛО: [ответ ИИ]` — замер честности ответа нейросети в %.
   * `НАВИГАТОР: [проблема]` / `ВЫРОЖДЕНИЕ: [правило]` — проверка постановки задачи и тест регламента на краях.

## 3. БЫСТРЫЙ СТАРТ ДЛЯ РАЗРАБОТЧИКОВ (MCP SERVER)

Чтобы подключить «Падежный фильтр» как системный предохранитель в **Claude Desktop** или **Cursor**, добавьте в файл конфигурации (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "case-filter": {
      "command": "python3",
      "args": ["/абсолютный/путь/к/папке/case_filter_mcp_server.py"]
    }
  }
}
```

После перезапуска ИИ-агент получит три системных инструмента:
* `verify_statement` — блокировка галлюцинаций, пассива и цифр без базы до отправки текста.
* `audit_contract_clause` — проверка пунктов договора на «резиновые» сроки и пустое кресло.
* `get_cell_registry` — справочник клеток `1–18 + R6`.

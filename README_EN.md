Turns any LLM into a strict structural auditor: exposes hidden passive voice ("Empty Seat"), rubber deadlines, unanchored metrics, unexecuted promises, and LLM hallucinations.

## 1. REPOSITORY MAP (3 BEST BUILDS WITHOUT DUPLICATES)

1. **[`macro-os-v8.0-autopilot-en.md`](./macro-os-v8.0-autopilot-en.md)** ([`Русский`](./macro-os-v8.0-autopilot.md)) — **"Autopilot" (1-Step Start Without Commands)**:
   * Best for quick onboarding. Paste the file at the start of a chat and send any text (contract clause, news item, official reply, or AI output) with no commands — the system detects the text type, audits it across 5 semantic roles, and provides a clean rewrite.
2. **[`macro-os-v9.5-complete-en.md`](./macro-os-v9.5-complete-en.md)** ([`Русский`](./macro-os-v9.5-complete.md)) — **"The Complete Four-Contour Console"**:
   * Lightweight main workstation with "dormant modes" (saves chat context tokens). Includes contours for text purification (`ONION:`), contract drafting and adversarial defense (`CONSTRUCTOR:`, `CROSS-CHECK:`, `DEVIL'S ADVOCATE:`), AI & multi-step project auditing (`MIRROR:`, `CHAIN:`, `RESOURCE:`, `PRE-BUILD:`), and problem deconstruction (`NAVIGATOR:`, `DEGENERACY:`).
3. **[`macro-os-v7.0-tribunal-en.md`](./macro-os-v7.0-tribunal-en.md)** ([`Русский`](./macro-os-v7.0-tribunal.md)) — **"Tribunal & Arbitrage"**:
   * Adversarial review of disputed records across three isolated contours (**Prosecutor / Defender / Judge**) with a Divergence Index, plus cross-model `ARBITRAGE` to audit verdicts from other LLMs.

## 2. QUICK START IN 30 SECONDS

1. Open a new chat in **ChatGPT, Claude, Gemini, or DeepSeek**.
2. Open your chosen file above (beginners should start with [`macro-os-v8.0-autopilot-en.md`](./macro-os-v8.0-autopilot-en.md)), copy its entire content, and send it as your first message.
3. Paste any text to audit or trigger specialized console modes (`ONION:`, `CROSS-CHECK:`, `CONSTRUCTOR:`, `DEVIL'S ADVOCATE:`, `TRIBUNAL:`, `MIRROR`).
